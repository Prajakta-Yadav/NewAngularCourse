Position, Z-index, & Opacity

  • Above Program I have used position, z-index, and opacity property.
  • Two div box has same position value absolute is used.
  • Box1 background-color is blue and z-index value is -1
  • Box2 background-color is black and z-index value is 1
  • Opacity:
    • We use opacity property for controls the transparency of an element.
    • Opacity property range values are between 0 to 1
    • 0 is full transparent
    • 1 is fully visible
  • position:
    • We use position property for define how an element is positioned in the document.
    • Above Program I have used position values is absolute which has take positioned relative to nearest positioned ancestor.
    • Total five values are position property: static, relative, absolute, fixed, sticky.
  • Z-index:
    • We use z-index for controls stacking order of overlapping elements.
    • It's works only on positioned elements
    • Higher value appears on top
    • z-index property values can be negative.
