# Product Dashboard With API Integration

## Features
- Fetch products from a public API
- Responsive product grid
- Search filter
- Sort products by price, name, and rating
- Category filter
- Add to cart
- Persist cart in local storage
- Handle API errors with retry
- Loading indicator
- Theme toggle with persistence
- Product details modal

## API Used
- Fake Store API: `https://fakestoreapi.com/products`

## Run Locally
1. Download or clone the project.
2. Open `index.html` in a browser.
3. For the smoothest API behavior, use a local server such as VS Code Live Server.

## Files
- `index.html` – page structure
- `styles.css` – UI styling and responsive layout
- `script.js` – API integration, filters, cart, error handling, theme toggle
