# Personal Portfolio – Professional Version

A responsive one-page portfolio for **Prajakta Yadav** built with clean structure and production-friendly files.

## Features
- Hero, About, Skills, Projects, Contact, Footer
- Smooth scroll navigation
- Animated skill bars
- Project modal preview
- Contact form validation
- Dark/light theme toggle with local storage
- Draft contact form persistence in local storage
- Responsive layout
- Minified CSS and JS
- Lightweight asset strategy (no large local images)

## Files
- `index.html`
- `style.min.css`
- `script.min.js`

## Resume-based content
This portfolio uses information from the provided resume for the summary, experience highlights, skills, projects, location, email, and phone details.

## Run locally
Open `index.html` directly, or use a local server for the best experience.

## Deploy on Netlify
1. Create a new site from the project folder.
2. Set publish directory to the project root.
3. Deploy.
4. Optional: connect a Git repository for continuous deployment.

## Deploy on GitHub Pages
1. Push the project to a GitHub repository.
2. Go to **Settings → Pages**.
3. Choose deployment from the main branch/root.
4. Save and wait for the live site URL.

## Image optimization note
This version avoids heavy image assets and uses gradient placeholders to keep the project fast. Replace placeholders with optimized WebP images later if needed.

## Suggested customization
Replace placeholder social links, add a profile image, and connect the contact form to a real backend or email service.
